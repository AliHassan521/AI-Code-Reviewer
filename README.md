# AI Code Reviewer

An AI-powered code reviewer that analyzes code, identifies potential issues, and provides suggestions for improvement using Google's Generative AI API.

## 🚀 Features
- Automated code reviews
- Suggestions for code optimization
- Error detection and bug highlighting
- Supports multiple programming languages
